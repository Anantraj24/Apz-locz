# Design rules
- Follow `docs/04_DESIGN_SYSTEM.md` tokens exactly; Samsung-inspired feel with original assets (no Samsung logos/fonts).
- One accent colour; status colours only for status. Light, dark and true-black dark all supported.
- System font only. Corner radii, spacing and motion per tokens.
- No infinite decorative animations, no heavy blur, no gradients except as specified.
- Lock screen is the priority screen: fast, calm, premium.
