# Global rules
- Read `AGENTS.md` and the phase section of `docs/09_DEVELOPMENT_ROADMAP.md` before acting.
- One phase at a time; stop for owner approval after each.
- Confirmed > provisional > open. Open items require asking the owner.
- No invented APIs, versions, libraries or features. Verify in official docs.
- Build and run before claiming anything works. Report evidence.
- Small diffs; no unrelated refactors; no deleting working code without reason.
- No secrets in code or logs. No INTERNET permission.
- Update docs and changelog when approved changes occur.
